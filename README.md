# Grave Client

A dark, purple-themed Minecraft launcher and installer concept built to match the look and feel of a premium client UI.

## Run it

### Windows

1. Install Java 17+
2. Install Maven
3. Double-click `install.bat`
4. Then run `run-launcher.bat`

### macOS / Linux

1. Install Java 17+
2. Install Maven
3. Run:

```bash
chmod +x install.sh run-launcher.sh
./install.sh
./run-launcher.sh
```

## Notes

This is a launcher starter for a custom Minecraft client. It includes:
- an installer script
- a dark purple launcher UI
- install/config folder creation
- launch support for a client jar or executable
